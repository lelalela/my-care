# My-Care (마이케어) 🏃‍♂️🩺

> **질환 맞춤형 운동 처방 및 지속 관리 모바일 서비스**  
> 나의 건강검진 결과(지방간, 전당뇨, 고혈압 등)에 딱 맞는 **안전하고 과학적인 운동 처방**과 일상 걷기/홈트/헬스 지속 관리 솔루션

---

## 📌 주요 특징

1. **질환 맞춤형 유산소 코칭**:
   - 질환별 권장 걷기 속도, 분당 걸음수(Cadence/SPM), 적정 시간 및 심박수 가이드
   - 식후 혈당 스파이크 억제(전당뇨), 내장지방 연소(지방간) 등 질환별 최적 운동 타이밍 안내
2. **다양한 환경 지원 (헬스장 / 홈트 / 맨몸)**:
   - 헬스 기구(레그프레스, 체스트프레스, 랫풀다운 등), 홈트레이닝(덤벨/밴드), 맨몸 운동(스쿼트, 월싯 등) 맞춤 추천
   - 인슐린 감수성 개선을 위한 하체/대근육 중심 루틴 구성
3. **하이브리드 안전 추천 엔진**:
   - 스포츠의학 및 공인 학회(대한당뇨병학회, 간학회, ACSM 등) 가이드라인 기반의 안전 필터링
   - 위험 동작(혈압 급상승, 관절 과부하, 발살바 호흡) 사전 차단 및 안전 대체 동작 제시
4. **지속 가능한 습관 관리**:
   - 일일 실천 스트릭, 주간 목표 달성률, 간단한 루틴 체크리스트

## 🏗️ 시스템 아키텍처

```text
my-care/
├── backend/                  # FastAPI 기반 추천 엔진 & API 서버
│   ├── app/
│   │   ├── api/              # API 엔드포인트 라우터
│   │   ├── core/             # 앱 설정 및 보안
│   │   ├── data/             # 질환별 스포츠의학 운동 가이드라인 데이터셋
│   │   ├── models/           # Pydantic & ORM 데이터 모델
│   │   └── services/         # 하이브리드 운동 추천 & 필터링 로직
│   └── tests/                # 백엔드 단위 및 통합 테스트
├── frontend/                 # Flutter 기반 모바일 클라이언트
│   ├── lib/
│   │   ├── features/         # 기능별 화면 및 상태 (온보딩, 유산소 코치, 루틴)
│   │   └── core/             # 테마, 센서 매니저, API 클라이언트
└── docs/                     # 기획 및 아키텍처 명세서
    ├── PRD.md
    └── ARCHITECTURE.md
```

---

## 🛠️ 기술 스택

- **Mobile Client**: Flutter 3.x (Dart 3.x)
- **Backend API**: FastAPI (Python 3.14+)
- **Database**: PostgreSQL / SQLite (로컬 개발용)
- **AI & Recommendation**: 질환별 의학 가이드라인 규칙 DB + LLM 맞춤화 엔진
